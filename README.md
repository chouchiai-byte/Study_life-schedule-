# 半時格 — 高中生時間管理網頁 App

每 30 分鐘一格，把一天切成 48 格，協助高中生安排讀書、作業與作息。
網頁 App（PWA）：用 iPhone 的 Safari 開啟並「加入主畫面」，就能像 App 一樣全螢幕使用、沒有網路也能用。
所有資料只存在這支手機的瀏覽器裡，不會上傳。

---

## 一、網站在哪裡

網址：<https://chouchiai-byte.github.io/Study_life-schedule-/>

網站放在 GitHub Pages（免費）。每次把程式推送到 `main` 分支，GitHub 會自動跑測試、建置並發布（約 1–2 分鐘），
孩子下次開啟 App 會自動更新，手機裡的資料不受影響。發布進度可在儲存庫的「Actions」分頁查看。

> 儲存庫是公開的，因此程式中**不放任何學校、班級、老師或住址資料**。課表另外以「課表檔」（.json）交給孩子，在 App 內匯入，只存在手機裡。

## 二、安裝到孩子的 iPhone

1. 用 **Safari** 開啟上面的網址（一定要用 Safari）。
2. 點下方「分享」按鈕 →「加入主畫面」→「加入」。
3. 之後從主畫面的「半時格」圖示開啟。
4. 匯入課表：把家長給的「課表檔」（.json）存到 iPhone 的「檔案」App（例如從 LINE 或 Email 存下來），到「課表」頁按「📥 匯入課表檔」選取。
5. 進入「今天」→ 右上角 ⚙️ →「提醒」→「允許通知」。
6. 第一次使用「拍照辨識」時，請在 Wi-Fi 下使用（會下載約 4.6 MB 的中英文辨識模型，之後可離線）。

## 三、每天怎麼用（記錄模式，像飲食控制 App）

每天的可支配格就像熱量預算：讀書目標由孩子自己訂，每 30 分鐘做了什麼隨手記一筆。

| 時間 | 動作 |
| --- | --- |
| 第一次開啟 | 「今天」頁按「設定目標」，自己決定上學日、假日各想讀幾格（1 格 = 30 分鐘） |
| 隨時 | 右下角「＋ 記錄」：自動選好最近一格還沒記的時間 → 點類別（讀書再點科目）→ 完成，約 3 秒 |
| 看進度 | 首頁圓環顯示「還差幾格達標」，比例條顯示讀書／休閒／其他／未記錄 |
| 想先排計畫 | 「✨ 排程建議」或點未來的空格「安排讀書計畫」；計畫格打卡「完成」會自動記成讀書 |
| 讀書時 | 「⏱ 專注計時」：25 分鐘專注＋5 分鐘休息 |
| 睡前 21:30 | 提醒明天的課表、備忘，以及今天還有幾格沒記錄 |
| 每週一次 | 📊 週報 →「分享週報給家長」；「任務」左上「📅 匯出行事曆」；⚙️ →「匯出備份檔」 |

**記錄類別**：讀書（依科目）、作業、課程、休息、滑手機、擼狗、運動、其他休閒（可自訂名稱，例如彈吉他）、家事雜事。
休閒照實記錄，不扣分、不提醒；連續記錄天數可以隔天補登，不會因為漏一天就歸零。

**家長能看到的**：只有孩子分享的週報總數（讀書、休閒、其他時數，各科讀書時數，記錄完整度），不含每一格的明細。

週末的補習、複習課程：到「課表 › 課程與時段」新增，會自動扣除可支配格。颱風假、補假：「課表 › 停課日」。

## 四、資料與備份

- 資料存在 iPhone 的 Safari 網站資料中。**刪除主畫面圖示、清除 Safari 資料或換手機，資料會不見。**
- 每週到 ⚙️ →「資料備份」→「匯出備份檔」，存到「檔案」或傳給家長。
- 還原：⚙️ →「從備份檔還原」，選擇 `.json` 備份檔。

## 五、第一版的限制

- **App 關閉時不會自己跳通知**：網頁 App 無法在背景排定提醒。請每週匯出行事曆，交給 iPhone 行事曆提醒。第二階段會架設推播伺服器。
- **拍照辨識**：印刷文字（講義、通知單、考卷題目）效果好；黑板手寫效果有限，第二階段改用雲端 AI（需家長同意）。
- **PDF**：筆記「PDF」按鈕會開啟列印畫面，在 iPhone 選「分享 → 儲存到檔案」即可得到 PDF。Word 匯出在第二階段。

## 六、給開發者

需要 Node.js 20 以上（Windows 也可以）。

```bash
npm install
npm run dev          # 開發模式，手機與電腦同一個 Wi-Fi 可用 http://電腦IP:5173 測試
npm test             # 單元測試（41 項：半時格計算、自動排程、衝突檢查、記錄模式、統計、辨識後處理、備份）
npm run build        # 產生 dist/，就是要上傳的網站
npm run build:single # 產生單一檔案預覽版 dist-single/index.html
```

| 資料夾 | 內容 |
| --- | --- |
| `src/core/` | 排程核心：格序換算、每日 48 格配置、自動排程、衝突檢查、記錄模式（logs.ts）、統計、預設課表 |
| `src/db/` | IndexedDB（Dexie）資料表、備份還原、常用操作 |
| `src/pages/` | 今天、週格、任務、課表、筆記、設定、週報、專注計時 |
| `src/services/` | 提醒、行事曆匯出、文字辨識、筆記匯出、檔案分享 |
| `scripts/copy-ocr.mjs` | 把辨識程式與繁中／英文語言模型複製到 `public/ocr/`，由自己的網站提供 |

預設作息（可在 App 內修改）：06:30 起床、06:45 出門、07:30 到校、17:15 放學、通勤 45 分鐘、18:00 晚餐、21:30 洗澡、23:00–24:00 彈性就寢。
程式中不含任何學校、班級或老師資料；課表以「課表檔」（.json）匯入，只存在手機裡。
